This is a project of a game inspired by Doodle Jump but with more content. 

The goal of the game is to get as much points as possible and you do so by jumping up the platforms that fall from above. 
You also must avoid falling to the bottom or getting enemies close to you as it leads to a loss. 
If you lose, your score is saved to a JSON file and you can see it in the settings menu.

It's based on pygame technology and uses it to make a game. 

To run the game, you must make sure you have python and pygame installed.

To install pygame and then run the game:
1. Insert pip install pygame into command prompt
2. Download the project from github
3. Run the main.py
